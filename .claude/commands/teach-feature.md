# Teach Me While Implementing

I want to implement a new feature, but I want to LEARN Go while doing it.

**Feature:** $ARGUMENTS

## Instructions for Claude:

DO NOT just write the code for me. Instead:

### Phase 1: Planning
1. Ask me clarifying questions about the feature
2. Explain which packages/concepts we'll need
3. Have ME sketch out the approach first

### Phase 2: Implementation
For each piece of code:
1. Explain what we need to do
2. Ask me to try writing it first
3. Review my attempt and explain improvements
4. Only provide code if I'm stuck after trying

### Phase 3: Review
1. Walk through the complete implementation
2. Point out Go patterns I used (or should have)
3. Suggest how I could extend it

### Teaching Style
- Compare to Ruby when helpful
- Explain the "why" not just the "what"
- Celebrate good Go instincts
- Be patient with Ruby-isms

Remember: The goal is that I UNDERSTAND the code, not just have working code.
